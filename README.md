# Hanuman Mission: media kit

Hanuman Mission is a free 3D action game of the Ramayana that runs in the browser, on phones too. You play Hanuman's
night in Lanka: Lankini at the gate, finding Sita in the Ashoka grove and giving her Rama's ring, standing bound before
ten-headed Ravana, and growing to a giant. Made solo by Sid in under 80 hours for the Manycore Aholo Global 3D AI
Hackathon.

- Play: https://hanumanmission.com
- X: [@sid_ai_dev](https://x.com/sid_ai_dev)

Every character and prop was generated with Aholo Lux3D from one reference image each, then rigged (Lux3D auto-rig
and Mixamo), fixed in Blender and run in three.js.
